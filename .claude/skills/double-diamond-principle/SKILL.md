# Double Diamond（雙鑽石原則）

Design Council 提出、用來描述任何設計與創新專案步驟的簡單模型：用兩顆相連的鑽石，畫出
「先發散、再收斂」兩輪思考。2019 年擴充為 **Framework for Innovation**（雙鑽石置於核心，
外加設計原則、方法庫，以及 Engagement 與 Leadership 兩種文化條件）。

核心紀律是一句話：**先找對問題，再找對解法。**「從你要解決的議題出發，而不是從你想用的
解法出發。」本 skill 依官方 designcouncil.org.uk 整理；完整細節與出處見 `references/details.md`。

## 為什麼是兩顆鑽石

每顆鑽石都是「先張開、再收攏」：

- **發散思考（divergent）**：鑽石前半，更廣、更深地探索議題，盡量打開可能性。
- **收斂思考（convergent）**：鑽石後半，聚焦、篩選、定案，收攏到一個清楚焦點（鑽石腰身）。

兩顆鑽石 = 兩輪發散收斂：

- **第一顆鑽石 = Discover + Define = 處理「問題」**（找對問題）。腰身 = 清楚的問題陳述 / design brief。
- **第二顆鑽石 = Develop + Deliver = 處理「解法」**（找對解法）。腰身 = 可交付、經驗證的解法。

## 四個階段（The 4 Ds）

### 1. Discover（探索）- 第一顆鑽石前半 / 發散
- **目的**：理解問題本身，而不是假設問題是什麼。
- **做法**：與受影響的人交談、相處、觀察，找出共通的問題與需求。
- **產出**：第一手洞察、使用者需求、對議題的廣泛理解。
- **關鍵問題**：真正的問題是什麼？受影響的是誰？他們實際經歷了什麼？
- **檢核點**：我們是「理解」了問題，還是只是「假設」了問題？

### 2. Define（定義）- 第一顆鑽石後半 / 收斂
- **目的**：提煉整合洞察，用不一樣的角度重新框定挑戰。
- **做法**：收斂研究、畫因果鏈、拆分與合併各種挑戰，定義出真正要解的問題。
- **產出**：清楚、可行動的問題陳述 / design brief（第一顆鑽石腰身）。
- **檢核點**：問題陳述夠聚焦嗎？是從「議題」出發而非從「想用的解法」出發嗎？

### 3. Develop（發展）- 第二顆鑽石前半 / 發散
- **目的**：針對已定義的問題，產生多種不同的可能解法。
- **做法**：跨領域汲取靈感、與不同背景的人 co-design、大量發想、做早期原型。
- **產出**：多個概念、設計方案、原型雛形。
- **檢核點**：方案夠多元嗎？是共創還是閉門造車？

### 4. Deliver（交付）- 第二顆鑽石後半 / 收斂
- **目的**：測試、篩選、精煉解法。
- **做法**：小規模測試，淘汰行不通的、改良可行的，捨棄無法規模化者。
- **產出**：經驗證、可上線 / 可擴大的最終解法（第二顆鑽石腰身）。
- **檢核點**：解法經過真實測試了嗎？失敗的是否果斷放棄？

## 四個設計原則（貫穿全程，非某一階段才做）

1. **Put people first（以人為本）**：從理解使用服務的人出發——他們的需求、長處與渴望。
2. **Communicate visually and inclusively（視覺化且共融地溝通）**：幫團隊與相關人建立共同理解。
3. **Collaborate and co-create（協作與共創）**：一起工作、向別人正在做的事學習。
4. **Iterate, iterate, iterate（反覆迭代）**：及早發現錯誤、降低風險、建立對點子的信心。

## 如何實際跑一輪

照四階段推進，每階段設關鍵問題與檢核點（見上）。兩個文化條件要同時營造：

- **Engagement（參與）**：與交付者、接收者及其他夥伴一起工作，把「關係」看得和「點子」一樣重要。
- **Leadership（領導）**：鼓勵創新、容許實驗與學習、邊做邊展示成果，為創新創造條件。

## 適用條件與常見誤解

**適合**：問題定義不清、需先釐清「真問題」的創新專案；以人為核心的服務 / 產品 / 政策設計；
需要跨領域協作與實驗的開放式挑戰。

**最重要的提醒：這不是一次性的線性流程。**

- ❌ 以為一條直線一次走完 → ✅ 可反覆往返、各階段可能重跑的迭代流程；Discover 可能揭露更深的
  問題而把團隊送回起點，early prototyping 本身也可算 discovery 的一部分。
- ❌ 以為是「一步步教你怎麼設計的說明書」→ ✅ 它是描述流程的共同語言、「邀請你參與」，不是硬性手冊。
- ❌ 跳過第一顆鑽石直接做解法 → ✅ 核心紀律正是「先找對問題」。
- ❌ 把發散當成全程 → ✅ 每顆鑽石都必須在後半收斂出明確焦點才能推進。

## 各階段常用方法（實務常見對應）

> 官方方法庫（Methods Bank）把方法依用途分 **Explore / Shape / Build** 三類，比喻為可自由
> 組合的「食材」，但未逐字列出個別方法名稱。以下為設計實務常見對應，非官方逐字清單：

- **Discover**：user research / 深度訪談、田野觀察（ethnography）、stakeholder interviews、問卷。
- **Define**：洞察綜整（synthesis）、affinity mapping、因果 / challenge mapping、personas、journey mapping、problem statement。
- **Develop**：brainstorming、co-design / co-creation 工作坊、sketching、概念發展、prototyping。
- **Deliver**：usability / user testing、小規模 pilot、方案比較、iteration、上線與持續優化。
